# Chapter 25: Log Analyser and IOC Extractor

**Status: planned.** Track: Detection and defence. Depends on: Chapter 4.

## Objective

Parse web and auth logs into structured events and extract indicators (IPs, hashes, user agents, paths), producing the summary a responder needs in the first minutes of an incident.

## The mechanism, in outline

- Log formats are grammars; one robust parser per format (combined, auth.log, JSON) turns text into queryable events.
- Aggregation is the analysis: counts by source, by path, by result, over time buckets.
- IOC extraction is pattern work: hashes, IPs, domains, and the discipline to defang them in reports.

## What you will build

A working implementation in Python, in this directory, following the
anatomy of the completed chapters: numbered build steps, a runnable
tool, a smoke test against self-owned lab targets, and exercises.

## Exercises (draft)
